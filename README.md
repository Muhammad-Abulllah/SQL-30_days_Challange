# 📘 30 Days SQL for Data Analysis

This repository documents my **30-day structured SQL learning journey** focused on **data analysis use cases**, business queries, and interview-relevant problem solving.

The goal of this challenge was not just learning SQL syntax, but applying SQL to **real-world analytical scenarios** such as KPIs, trends, joins across tables, and data quality checks.

---

## 🗓️ Challenge Structure

### 🔹 Week 1: SQL Fundamentals
**Focus:** Data retrieval and filtering

- Day 1: SELECT, FROM, database basics  
- Day 2: WHERE clause  
- Day 3: AND / OR / NOT  
- Day 4: IN, BETWEEN, LIKE  
- Day 5: ORDER BY, LIMIT  
- Day 6: DISTINCT & data exploration  
- Day 7: Practice problems (LeetCode-style)

**Outcome:** Ability to confidently extract and filter data

---

### 🔹 Week 2: Aggregations & KPIs
**Focus:** Summarizing data for analysis

- Day 8: Aggregate functions (COUNT, SUM, AVG, MIN, MAX)  
- Day 9: GROUP BY  
- Day 10: HAVING vs WHERE  
- Day 11: Conditional aggregations  
- Day 12: Date-based grouping  
- Day 13: Multi-column GROUP BY  
- Day 14: Aggregation challenge

**Outcome:** KPI calculation and metric-based analysis

---

### 🔹 Week 3: Joins & Relationships
**Focus:** Multi-table analysis

- Day 15: INNER JOIN  
- Day 16: LEFT JOIN  
- Day 17: RIGHT JOIN & FULL JOIN concepts  
- Day 18: Joining multiple tables  
- Day 19: Handling NULL values  
- Day 20: Missing data detection using LEFT JOIN  
- Day 21: Join-based analytical challenge

**Outcome:** Working confidently with relational databases

---

### 🔹 Week 4: Advanced SQL for Analytics
**Focus:** Analytical and interview-ready SQL

- Day 22: Subqueries  
- Day 23: Common Table Expressions (CTEs)  
- Day 24: Window functions (ROW_NUMBER, RANK)  
- Day 25: Running totals & moving averages  
- Day 26: CASE statements  
- Day 27: Data validation & quality checks  
- Day 28: Query optimization basics

**Outcome:** Writing scalable, readable analytical SQL

---

### 🔹 Final Phase: Real-World Application
- Day 29: End-to-end SQL practice case  
- Day 30: Sales & customer analysis mini case study  

**Outcome:** SQL used for decision-making, not just querying
